# SÍ PUEDO · INVICTO

Aplicación web personal para organizar el día, las tareas, la casa, el tiempo, las finanzas y la agenda. HTML, CSS y JavaScript sin dependencias ni compilación.

**App publicada:** https://sipuedo-invicto.github.io/si-puedo/

Los datos se guardan solo en el navegador del dispositivo (`localStorage`, clave `aturitmo-v1`). Este repositorio contiene únicamente el código: ningún dato personal se sube aquí. Haz copias desde «Guardar copia».

## Instalar en iPhone
Abre el enlace en Safari → Compartir → Añadir a pantalla de inicio. Usa siempre el icono instalado.

## Desarrollo
- `node serve.cjs` y abrir http://127.0.0.1:4173/
- Pruebas: `node tests/finances.cjs`, `node tests/time.cjs`, `node tests/agenda.cjs`
- `logos/` guarda los recursos gráficos de versiones anteriores (no se cargan en la app).
- Historial de cambios: `CAMBIOS.md`.
